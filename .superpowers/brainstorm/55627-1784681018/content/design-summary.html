群控首版设计汇总

确认无误后，我会把规格写入 docs/superpowers/specs/ 并提交，再进入实现计划。

目标

本机 2–10 个浏览器实例主从同步操控，配合桌面置顶悬浮条与均匀平铺。

交互
  • 实例列表多选 → 在已选中用单选指定主实例（显示实例名）→ 开始群控。
  • 启动桌面级置顶、可拖动悬浮条：暂停 / 恢复、平铺、结束、状态。
  • 「平铺」铺到悬浮条所在显示器，自动均匀网格。
同步
  • 点击、页面内键盘输入、滚动、标签新建/关闭/切换。
  • 地址栏：导航结果同步（回车后跳同一 URL；含前进/后退/刷新），不逐字镜像。
  • 页面结构需基本一致；不做浏览器菜单、扩展弹窗、文件选择器、跨设备。
架构
  • Wails v2 辅助进程：无边框置顶控制条 + 本地 IPC。
  • 主进程为唯一状态源：会话、操作队列、标签映射、自动/手动暂停。
  • 常驻 CDP：主实例捕获，从实例回放；覆盖 macOS / Windows / Linux。
异常
  • 从实例失败 / 掉队 / CDP 断线 → 整组自动暂停并标出异常实例名。
  • 可重试对齐、移出该从实例，或手动恢复后继续。
